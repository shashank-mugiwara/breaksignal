# Learnings

Lessons from work in this repo. One line each, newest last. JStack's weekly step reads this file and turns
lessons that repeat into changes to a skill or an agent (docs/SCOPE.md, section 6).

Format: `- YYYY-MM-DD [skill-or-agent name] what to do differently. Seen in: <bead id, sha, or command and output>`

Write the skill or agent name in the brackets. A line without one is still read, but lands under "names no
skill or agent" and waits for someone to place it.
